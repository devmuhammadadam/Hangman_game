# Hangman Game 🎮

An interactive word-guessing game built with HTML, CSS, and JavaScript.

## Overview

Hangman is a classic word-guessing game where players try to discover a hidden word by guessing its letters one at a time.

Each incorrect guess brings the hanging rope closer to the character. Players must guess the word before running out of attempts. If all allowed mistakes are used, the character is hanged and the player loses the game.

## Features

- **Hidden Word Guessing:** Discover a hidden word by guessing its letters.
- **Interactive Gameplay:** Make guesses and track your progress.
- **Limited Attempts:** Play with a limited number of incorrect guesses.
- **Visual Progression:** Watch the hanging rope approach the character with each wrong guess.
- **Win or Lose:** Win by guessing the word correctly, or lose when all attempts are exhausted.
